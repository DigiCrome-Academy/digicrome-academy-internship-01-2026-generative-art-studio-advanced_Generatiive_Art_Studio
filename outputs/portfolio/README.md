# outputs/portfolio/

Put your **Generated Art Portfolio** deliverable here: 50+ curated images
showcasing your models' capabilities (see docs/PROJECT_BRIEF.md,
deliverable #4, and docs/RUBRIC.md's "Portfolio & Presentation" — 5%,
manually reviewed).

Suggested organization:

```
outputs/portfolio/
├── vae_samples/
├── dcgan_samples/
├── conditional_gan_samples/
├── style_transfer/
└── platform_exports/       # images exported via the Streamlit app
```

Images themselves are git-ignored (see `.gitignore`) — this README is kept
so the folder exists in a fresh clone. Ask your instructor how they'd like
the final portfolio submitted (zipped, uploaded elsewhere, etc.) if it's
too large for git.
